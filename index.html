What this site covers

Every command in the BW BricsCAD Tools suite is documented here — what it does, what it prompts for, what it draws and on which layer, and the things worth knowing before you run it. The command pages are generated from the shipping plugin source, so they describe the tools as they actually behave.

If you reached this site from a Help button on one of the ribbons, use the section navigation on the left to find the tool you were using.

Finding a command

If you know the command name, the command reference lists every command alphabetically and by ribbon panel, with a filter box to narrow it down. Commands are shown the way you'd type them, like AUTODIM or SETLAYOUT.

Note — a number of commands have no ribbon button and are typed at the command line. Those are listed in the command reference too, so it's worth a browse even if you only use the ribbon.
