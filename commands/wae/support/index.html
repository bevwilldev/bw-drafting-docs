Support

The Support panel sits at the start of every ribbon tab: one button opens these docs, the other reports a problem or suggests a tool.

WAEHELP

Opens the Works-As-Executed documentation in your browser — the ribbon's Help button.

How to use it

No prompts. If the browser can't be opened it says so on the command line.

WAEBUG

Opens the Support & Requests form — the ribbon's Report a Bug button.

How to use it

No prompts. Use it for anything odd, and for tool ideas too: the form asks what kind of request it is and only shows the relevant questions.

Note — Reports go straight to the Western Sydney Drafting team. While the suite is in early access this is the main feedback channel, and fixes usually reach you automatically within a day or two.
