Sheeting

Bringing the design sheet into the Works-As-Executed drawing.

IMPORTSHEET

Turns a folder of scanned or exported design sheets into a set of layouts — one per image, named after the file, with the image stretched to fill the sheet and the page already set up to plot.

This is the starting point for a works-as-executed job: import the design sheets, then mark them up in red.

How to use it

Run it and answer Specify sheet size [A4/A3/A2/A1]: — Enter takes the A1 default. A file dialog opens (at the drawing's Rasters folder if there is one) where you can select many images at once. If some of them already have layouts you're asked once, N of the selected sheet(s) already have layouts [Replace/Skip]:, defaulting to Skip. Progress is reported per sheet and it finishes on the first layout it created.

What it produces

A layout per image, its default viewport erased and the raster attached on the SHEET layer, stretched to the paper size. Each layout is configured for Print As PDF.pc3 at the chosen media, millimetres, rotated 90°, centred, plot type extents, with the BW_FINAL.ctb plot style table shown, and opens zoomed to extents.

Note — The whole import is one undo group — a single U removes every layout it made. Characters that layout names can't hold are replaced with hyphens, and a file whose name leaves nothing usable is skipped. If the PDF plot device is missing the sheets still import at standard ISO sizes, but you're warned once that the plot setup was skipped.
