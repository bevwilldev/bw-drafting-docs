Annotations

WAE text, grades, comments and the certification tick.

ADDCOMMENT

Writes the office certification paragraph in full, with the registered surveyor's name and the surface layer filled in — the block of text that goes on the front sheet of every WAE set.

How to use it

Three prompts: Select Surveyor [Ben/Angela/Peter]:, which expands to the surveyor's full registered name; Select Surface type [First/Second/fInal]:, the AC layer the road centrelines were taken on; then Specify point to place text:.

What it produces

One MText block 150 units wide at 2.5 height in the WAE LABEL style, on layer ANNOTATIONS. It covers the work-as-executed certification, interallotment drainage within easements, the road centreline layer, Australian Height Datum, and pit and pipe sizes being as per design — followed by a signature rule and a line reading ADD DATE AND COMMENTS HERE.

Note — The surveyor list is fixed in the command. A name that isn't on it has to be typed over afterwards.

CALCGRADE

Computes a grade from two levels and a distance and places the result as a labelled percentage, so pipe and road grades can be annotated straight off the surveyed levels without a calculator.

How to use it

It loops so you can do several in a row. For each grade: Select first level or press Enter to input manually: — pick a text entity and the first number in it is read out, or press Enter and answer Enter first level:. The same for the second level. Then Choose chainage method [Direct/Calculate]: — Direct asks Enter chainage directly:, Calculate asks for a first and second length and uses the absolute difference, echoing what it worked out. Finally Specify point to place <grade> grade text:, with the computed value already shown in the prompt. Esc finishes.

What it produces

MText at 2.5 height, middle-centre, in the WAE LABEL style on layer ANNOTATIONS, reading the grade to one decimal place with a percent sign — for example 1.5%. The calculation is (first level − second level) ÷ chainage × 100.

Note — A chainage of zero is rejected — it says Chainage cannot be zero. and starts the cycle again rather than failing. A selected text with no number in it gives Invalid selection, try again.

FLIPTEXT

Fixes annotation that has ended up upside down — usually after a marked-up sheet has been rotated. Rotating about the middle centre means the text stays where it was rather than swinging away from the feature it labels.

How to use it

Select the text first if you like, otherwise it asks for a selection filtered to text and mtext. No further prompts; it reports Text flipped 180 degrees with Middle Center attachment.

What it produces

Edits the selected entities in place: attachment or justification is set to middle centre and the rotation is increased by 180°.

Note — The justification change is permanent, so flipping twice returns the text to its original angle but not to its original justification.

HTXT

Quick annotation on a WAE sheet at a fixed horizontal rotation, so you can letter a rotated or imported sheet without fighting the UCS or the drawing's angle base.

How to use it

Run it, answer Text insertion point:, then type the text in place and finish as normal. Because the WAE LABEL style has a fixed height you are never asked for one.

What it produces

Single-line text at 0°, top-left justified, on layer ANNOTATIONS in the WAE LABEL style (Lucida Sans Unicode, fixed 2.5 height — not annotative, because WAE sheets are worked at paper scale). Colour, linetype and lineweight are set ByLayer.

Note — ANGBASE is temporarily zeroed so the text lands at a true 0° whatever the drawing's angle base is, then restored when the text command ends.

MODTEXT

Bulk-edits marked-up annotation by adding the same string to the front or the back of each selected item.

How to use it

Select the text first if you like, otherwise it asks for a selection filtered to text, mtext and multileaders. Then Choose [Prefix/Suffix]: and Enter text for Prefix/Suffix: (spaces allowed). It reports Modification completed.

What it produces

Edits the selected entities in place; nothing is created. Multileaders are only edited when their content is mtext.

Note — This is the WAE ribbon's own command. The engineering and drafting ribbons carry TADD, which does the same job and also handles dimension text.

VTXT

The vertical companion to HTXT — for labelling down the side of a sheet or along a vertical feature.

How to use it

Run it, answer Text insertion point:, then type the text in place. No height prompt — the WAE label style has a fixed height.

What it produces

Single-line text at 270°, top-left justified, on layer ANNOTATIONS in the WAE LABEL style at its fixed 2.5 height.

Note — Like HTXT, it zeroes ANGBASE for the placement and restores it afterwards.

WAETICK

Drops the standard WAE tick — the mark used to sign off items checked against the design — as many times as you need in one run.

How to use it

Run it and answer Specify insertion point: for each tick. It keeps asking until you press Esc.

What it produces

Block references of the waetick block on layer ANNOTATIONS, with colour, linetype and lineweight ByLayer. The block definition is imported from Support\waetick.dwg beside the plugin on first use and reused afterwards.

Note — If the block drawing is missing you get [BW WAE] waetick.dwg not found beside the plugin — reinstall the WAE component.
