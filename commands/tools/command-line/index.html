Commands without a ribbon button

Office-tool commands typed at the command line.

NSWLABELLOTS

Adds lot labels to boundaries that the lot loader brought in earlier — useful when you imported without labels, deleted some, or want them back after tidying up. It reads the plan details from the xdata the loader attached rather than going back to the web service.

How to use it

Select the lot boundaries first if you like, otherwise it asks to Select lots to label:, filtered to polylines. It reports [NSWLotLoader] Applied labels to N lot(s).

What it produces

One MText per lot at an interior point of the boundary, middle-centre at 1.0 height, holding the lot number, section number and plan label on separate lines. Boundaries on SUB BDY are labelled onto SUB DP (yellow); everything else goes onto ADJ DP (white). The layers are created if they don't exist.

Note — It only works on polylines carrying NSW_PARCEL xdata — boundaries drawn by hand or brought in another way are silently skipped. It doesn't check whether a lot is already labelled, so running it twice on the same selection doubles the labels up. There is no ribbon button; type the command.

NSWLOTSUPDATE

Refreshes the loaded cadastre. It removes everything the lot loader has drawn in the current drawing, then re-runs your last saved lot search — so the boundaries, labels and road data match what NSW Spatial holds today instead of the day you fetched them.

How to use it

Type the command. The panel opens with your last search restored and fetches automatically; if there's no saved search it says so and waits for you to enter lots.

Note — the clear-out happens before the re-fetch, so if the fetch fails (offline, service down) the drawing is left without its cadastre — one undo brings the old data back.

NSWLOTSDELETE

Removes everything the lot loader has drawn in the current drawing — boundaries, labels, road names, centrelines and the attribution stamp — and reports the breakdown. It finds its own work by the xdata tags it attaches when drawing, so your own linework on the same layers is never touched. Undo restores the lot.

Watch out — lot labels placed by versions before v2.3 carry no tag and are left behind; delete those by hand if present.

NSWFETCH

The NSW pipeline of GeoFetch, opened directly instead of through the manager. Same dialog, same result — useful when NSW is all you ever fetch. GEOFETCHNSW is a kept alias for it.

The companions are NSWFETCHUPDATE, which re-fetches everything the drawing already holds so the data is current, and NSWFETCHDELETE, which removes it. Both work from the fetch record kept in the drawing, so they only touch what GeoFetch drew. GEOFETCHUPDATE and GEOFETCHDELETE are kept aliases for the same two.

Note — update is all-or-nothing: it refreshes every dataset in the record, not just the one that's gone stale, so it costs a full fetch. There's no undo step beyond BricsCAD's own U.

AKLFETCH

The Auckland pipeline — landbase, addresses, the Unitary Plan, contours, flood and stormwater layers from Auckland Council. AKLFETCHUPDATE and AKLFETCHDELETE refresh and remove it the same way as the NSW pair.

Auckland's contours come from the council's 2024 LiDAR survey, at intervals from 0.25 m to 10 m — the dialog labels them so, and they're better quality than the NSW terrain options.

VICFETCH  /  QLDFETCH

Victoria and Queensland — cadastre, addresses, roads and planning zones from each state's open data service. VICFETCHUPDATE, VICFETCHDELETE, QLDFETCHUPDATE and QLDFETCHDELETE complete the set.

Note — Victoria is locked to MGA2020 Zone 55 and refuses anything else rather than projecting a job into the wrong zone. Western Victoria (Zone 54) is not covered.

AKLCONVERT

Converts existing drawing geometry between NZTM2000 and Mount Eden Circuit 2000 — the two grids an Auckland job moves between. It transforms what you select in place, keeping arcs as arcs rather than chording them.

Note — the selection is capped at 500 m across. That limit is deliberate: the transformation is exact enough to be invisible within it (well under a millimetre), and beyond it the error would start to matter. Convert in pieces if you need more.
