Tools

The NSW Lot Loader, Point Cloud Digitizer and GeoFetch.

NSWLOTS

Opens the lot loader, which pulls cadastral boundaries, lot labels, road names and road centrelines straight from the NSW Spatial service into model space. Lots can be found by lot and plan number, by picking a point, or by an extent.

The panel is modeless, so it stays open while you work in the drawing. The ? button in its title bar opens offline help.

How to use it

The command itself has no prompts — it just shows the panel, and everything happens in the form. Set the import options (subject and adjoining lot labels, road names, road centrelines), choose one of the three searches, and click Fetch Lots. Entries and settings are remembered for next time.

What it produces

Polylines and MText on the office cadastral layers: SUB BDY and SUB DP for the lots you asked for, ADJ BDY and ADJ DP for neighbours and the surrounding buffer, ROAD NAME and ROAD CL for roads. The By Point and By Extent searches put everything on the ADJ layers. Lots already loaded are skipped rather than duplicated. Each boundary carries the parcel details as NSW_PARCEL xdata.

Note — It needs internet access to the NSW Spatial service. The MGA zone is worked out from the fetched data; if it can't be determined the tool assumes Zone 56 and says so in the status bar — worth checking on a Zone 55 job.

PCDIG

Shows or hides the digitizer panel, which traces features off a point cloud — stepping along at a fixed distance per vertex, or tracing freely — with every vertex snapped to the cloud, numbered and coded as it goes. Each drawing gets its own panel.

The panel's buttons run the companion commands: PCDIG_LINE (Add Line), PCDIG_POINT (Add Point), PCDIG_EXTEND (Extend an existing 3D polyline) and PCDIG_EXPORT (Export to 12da).

How to use it

The command itself has no prompts — it toggles the panel. Set the segment distance, point numbering, point code and layer (manually or from a Trimble .fxl feature library) in the panel, then start a run. Digitising prompts Pick point (Esc to exit): with an Undo keyword that steps back a vertex; Extend asks you to Select polyline near the end you wish to extend:.

What it produces

3D polylines and, optionally, survey points on the feature's layer — Civil points where the Civil module is available, otherwise standard points with the number and code attached. The layer is created from the feature library's colour if it doesn't exist. Export to 12da… writes the digitised strings and points to a 12d Model ASCII file.

Note — While digitising, 2D object snaps are turned off and point-cloud nearest snapping is turned on, and PDMODE/PDSIZE are set for point visibility if they were at their defaults — all restored when the run ends. A locked target layer stops the run before it starts. The export can't run while a digitising run is active.

GEOFETCH

Opens the GeoFetch manager, which pulls published government spatial data straight into the drawing — cadastre, addresses, roads, zoning, planning overlays, hazards, utilities and terrain. Four regions are covered: NSW, Victoria, Queensland and Auckland, each with its own dialog and its own datasets.

How to use it

The command has no prompts — it opens the manager, and you pick the region. Each region's dialog asks for a centre point (type the coordinates or use Pick <), a window size, and which datasets you want; then Fetch. Settings can be saved as named profiles for next time.

What it produces

Ordinary polylines, text, hatches and points on layers prefixed for the region (GEO-, VIC- and so on), plus an attribution stamp. Nothing is a custom object — the drawing looks the same on a machine without the plugins.

Terrain is context, not survey — the Elevation options are built from a 5 m source. See Elevation data before using them on a job. Contours and surfaces from GeoFetch are for extent, fall and feasibility; design levels need a real survey.
Note — A fetch holds BricsCAD until it finishes and Esc will not interrupt it. A large multi-dataset fetch can take minutes and looks like a freeze; it isn't, and it always comes back. Utilities and easements are indicative only — a Before You Dig enquiry is still mandatory. Full guide: GeoFetch.
