STRAIGHTLEADER / CURVELEADER

Label leaders — straight-segment or spline — whose text matches your current style.

Ribbon · Text → Straight Leader / Curved Leader

How to use it

Both run the native MLEADER command.

What it produces

The leader takes your current text style and height, so it matches surrounding annotation.

ATC

Aligns text along a curve with a live drag preview.

Ribbon · Text → Align Text to Curve

How to use it

Select text to align [New/Settings] <Exit>: — pick existing text, type New to type fresh text, or Settings to open the options dialog. Then pick the curve or multileader to align to, and drag into position.

While dragging: +/- step the offset, </> rotate, Y toggles readability, B toggles the background mask, O and R prompt for exact values.

What it produces

Aligns the picked text, or creates new text using the layer and style set in Settings.

Note — Settings has a Multiple mode that keeps placing copies down a line, and a Copy mode that leaves the original in place. Settings persist between sessions and are shared with CLABEL.

CLABEL

Type a phrase and drag each word onto a curve in turn.

Ribbon · Text → Align Custom Label

How to use it

Enter label words (space-separated): then drag each word onto a curve. The word list wraps, so you can keep going along a fence line.

What it produces

Text created with the shared ATC settings — on the layer and style those settings specify.

MTC

Drops each selected label into the middle of its lot.

Ribbon · Text → Move to Center

How to use it

Pre-select, or Select closed polylines and text:. Each label moves to the middle of the nearest lot that hasn't already taken a label. The select prompt also offers Placement, which decides what “the middle” means.

What it produces

Moves existing mtext; creates nothing.

Placement

The same four options are on ALAB, and your choice is remembered between sessions.

  • Fit (the default) — the best spot for the size of this label, so a wide label on a shallow lot does not overhang the frontage.
  • Roomiest — the point furthest from every boundary.
  • Centre — the true centroid.
  • Box — the centre of the extents; predictable, and it lines labels up across a row of similar lots.
Note — The label lands inside the lot, even on concave or L-shaped ones: every mode falls back to Roomiest rather than placing a label outside the boundary.

TBRK

Adds or removes brackets around selected text.

Ribbon · Text → Toggle Brackets

How to use it

Pre-select, or select text, mtext, leaders or dimensions. Each is toggled individually.

Note — Dimensions keep their live measured value.

TBG

Turns background masks on or off behind selected text.

Ribbon · Text → Toggle Background Mask

How to use it

Pre-select mtext, leaders or dimensions to toggle immediately, or run and use the Settings keyword to set the mask scale and colour first.

Note — Settings masks with the drawing background, a fixed colour, or Auto, which matches the colour of the hatch behind each label. Changing any setting turns the mask on rather than toggling it.
