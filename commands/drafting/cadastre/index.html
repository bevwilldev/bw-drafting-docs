Boundaries, lot numbers, areas, bearings, easements and roads.

Lot text

These all work the same way. Select text first and it's restyled in place — single-line text is converted to MText. Run with nothing selected and it loops, prompting Text insertion point [ESC to exit]: and opening the text editor at each point until you press Esc.

SUBBDY

Moves lot boundary lines onto the subject-boundary layer, or traces a new boundary.

Ribbon · Cadastre → Subject Boundary

How to use it

Select the boundary lines first, then run the command — they move straight to the layer with no further prompts. Run it with nothing selected and it hands off to the native -BOUNDARY command so you can pick internal points.

What it produces

Layer SUB BDY (cyan). Selected lines are replaced by two-vertex polylines; existing polylines are kept. Colour, linetype and lineweight are set ByLayer.

Note — Only lines and polylines are affected; anything else in the selection is left alone.

ADJBDY

The same thing for adjoining lots.

Ribbon · Cadastre → Adjoining Boundary

How to use it

Works exactly like SUBBDY — pre-select the lines to move them, or run with nothing selected to trace with -BOUNDARY.

What it produces

Layer ADJ BDY (white).

EASEA

Draws or converts easement outlines on the dashed easement layer.

Ribbon · Cadastre → Easement Area

How to use it

Pre-select easement outlines to convert them, or run with nothing selected to trace a new outline with -BOUNDARY.

What it produces

Layer EASEMENT (green, DASHED), drawn at a 0.25 linetype scale so the dashes read at plan scale.

Note — Needs the DASHED linetype loaded in the drawing.

EASEL

Draws easement boundary lines by hand.

Ribbon · Cadastre → Easement Lines

How to use it

Runs the native PLINE command on the easement layer — draw as normal.

What it produces

Layer EASEMENT, with the condensed linetype scale applied while drawing.

EASEARROW

Places an easement dimension arrow between two snapped points.

Ribbon · Cadastre → Easement Arrow

How to use it

Runs DIMALIGNED — pick the two points to dimension between. Intersection and insertion snaps are forced on while it runs.

What it produces

Layer EASEMENT LABEL using the EASEMENT LABEL dimension style.

Note — Your running object snaps are overridden while the command runs, then restored.

EASEP

Easement label leader — a spline leader with a dot arrowhead.

Ribbon · Cadastre → Easement Marker

How to use it

Runs the native MLEADER command — place the leader as normal.

What it produces

Layer EASEMENT LABEL, text style THIN LABEL.

ALIGNA

Stacks one text neatly under another at a fixed gap — typically an area under a lot number.

Ribbon · Cadastre → Align Area

How to use it

Prompts Enter offset value <2.0>: (the last value you used), then loops: Select the anchor text: → Select text to align with anchor:. The second text is moved below the first. Esc exits.

What it produces

Moves existing text; creates nothing. The gap accounts for both text heights plus your offset, scaled by the annotation scale.

Note — Only text and mtext are accepted. The offset value is remembered for the rest of the session.

STRETCHB

Splits a bearing into three separate texts — degrees, minutes and seconds — so each can sit over its own boundary segment.

Ribbon · Cadastre → Stretch Bearing

How to use it

Prompts Enter input method [Manual/Select]:.

  • Manual — asks for degrees, minutes and seconds in turn.
  • Select — pick an existing bearing text; it's parsed and erased.

You then drag-align each piece onto a curve in turn: degrees, then minutes, then seconds.

What it produces

Three MText labels, style SMALL LABEL on layer SUB BEARINGS.

CSUBB

The reverse of STRETCHB — merges three split bearing texts back into one label on a curve.

Ribbon · Cadastre → Condense Bearing

How to use it

Prompts for the degrees, minutes and seconds texts in turn. All three are erased and their contents joined, then you drag-align the combined label onto a curve.

What it produces

One MText, style SMALL LABEL on SUB BEARINGS.

Watch out — The three source texts are erased before you place the new label. If you cancel the placement, press U once to get them back.

ROADLM

Measures a road width between two points and writes (X.XX WIDE) at the midpoint.

Ribbon · Cadastre → Road Label (Measured)

How to use it

First point: → Second point:, with perpendicular and nearest snaps forced on.

What it produces

MText on layer ROAD LABEL, rotated to run across the road and flipped if needed to stay readable.

Note — Single shot — it doesn't loop.
