Commands without a ribbon button

Typed at the command line - a large part of the toolset, including the whole boundary dimensioning and curve table workflow.

The workflow

These commands are designed to run in sequence:

  1. AUTODIM dimensions every boundary segment and drops a numbered label on each curve.
  2. DIMRENUM tidies the numbering if you've edited things.
  3. CURVETABLE builds a schedule from those numbered labels.
  4. CURVETABLEUPDATE resyncs the table after further edits.

ANNOTOG

Shows or hides annotative objects at all scales, not just the current one.

How to use it

No prompts — it's a toggle, and reports the new state.

Note — Useful for checking what's attached to which scale. No ribbon button.

AUTODIM

Dimensions every segment of the selected lot boundaries in one hit — length inside, bearing outside, and a numbered label on each curve.

How to use it

Pre-select, or Select polylines/arcs:. Then Enter precision <3>: → Include bearings? [Yes/No] <Yes>: → Starting curve number: (defaults to this drawing's highest existing label plus one).

What it produces

Lengths on SUB DIMENSIONS, bearings on SUB BEARINGS, and a numbered curve label on DIM LABEL for each arc — the labels the curve table is built from.

Note — Re-running is safe: existing labels aren't doubled up, so it only fills in what's missing, and a boundary shared between two lots is dimensioned once. If a segment can't be dimensioned it's reported on the command line rather than skipped silently.

DIMLAB

Places numbered dimension-label bubbles, or converts existing text into them.

How to use it

Pre-select text to convert it. Otherwise Specify starting number: then place them one at a time; the number increments as you go.

What it produces

Dimension Label blocks on DIM LABEL.

Note — Numbering carries on from the highest number already in the drawing, skipping any that's taken.

DIMRENUM

Renumbers dimension labels in sequence, closing gaps left by deleted ones.

How to use it

Pre-select, or Select dimension labels to renumber: → Starting number <1>:. The select prompt also offers Sequence, which decides what order the numbers go in.

Sequence

  • Existing — keeps the order already on the labels and just closes the gaps left by deleted ones. This is what the command has always done.
  • Reading — renumbers top-down and then left-to-right, the way you read the sheet. Use it when the numbering has drifted out of step with the drawing.
Note — Your choice is remembered between sessions, and the command says which order it used. Reading order groups labels into rows by height band rather than comparing exactly, so two labels a whisker apart still count as the same row instead of one jumping the queue.

CURVETABLE

Builds a schedule of curved dimensions from the numbered curve labels, or exports them to CSV.

How to use it

In model space: pre-select, or Select dimension label blocks or Enter for all:. In a layout: it asks you to Select viewport(s): and includes only the labels visible in them. You can pick several — one at a time, by dragging a window across the sheet, or by selecting them before you run the command — so a layout with an overall and a couple of detail blow-ups gets one combined schedule instead of a table each. Either the viewport or its clip boundary works.

Then N curves — specify table insertion point or [Export]:. Export writes a CSV.

What it produces

A table titled Schedule of Short & Curved Dimensions on the TEXT layer, with columns for number, bearing, chord, arc and radius, sorted numerically.

Note — In a layout it lists only the curves actually visible in the viewports you pick, and a curve showing in two of them is listed once rather than twice. If none qualify, it tells you why on the command line.
Keeping it current — CURVETABLEUPDATE resyncs a placed table from every viewport it was built from. Delete one of them later and the table simply shrinks on the next update; it only loses its link when every source viewport is gone.

CURVETABLEUPDATE

Resyncs a placed curve table with the drawing — adds new curves, drops deleted ones, refreshes changed values.

How to use it

Select curve table to update or Enter to refresh all:.

Note — Only works on tables created by CURVETABLE. The table keeps the size it was created at, so it won't jump around if you've changed annotation scale.

CURVETABLEAUTO

Turns live curve-table refreshing on or off.

How to use it

A toggle — no prompts. The setting is remembered between sessions.

Note — On by default, so a placed curve table keeps itself current as you edit the labels it's built from. Turn it off if the redraw gets in the way on a heavy sheet.

DIMDATA

The inverse of CURVETABLE — reads a hand-drawn or imported curve schedule and writes its values back into the matching numbered labels.

How to use it

Pre-select, or Select the curve schedule text (window the whole table):.

What it reads

Three shapes of source data, including a table that mixes them:

  • A cell per text object — the older export, one piece of text per value.
  • A whole row in one line — the newer export, columns separated by spaces. Bearings written with spaces (128° 05' 12") stay in one piece, and the AutoCAD %%d degree code is understood.
  • Values annotated beside the curve — not a table at all, but separate text on the plan: 81°48'10", C6.685, A6.775, R12.070. Select them and DIMDATA replaces them with a proper numbered dimension label where the text was. C is the chord, A (or L) the arc, R the radius, and anything with degree marks is the bearing; lower case and an optional space or = are accepted. Where the arc and chord are equal and the plan writes them once as A&C6.685, both are filled from it. Bearings with the seconds left off (81°48') are read too, and the missing seconds written in as 00" so one sheet does not end up with two formats.
Note — The column order is read from the header, not assumed. A schedule headed No / Bearing / Distance / Radius / Arc holds the same data in a different order, and taking it at face value would write every radius into the arc and every arc into the radius — which looks entirely plausible on a plan. DISTANCE is understood as the chord, ARC LENGTH as the arc and CHORD BEARING as the bearing.
Note — Anything it cannot read stops it rather than letting it guess, so an ordinary selection of text is never mistaken for curve data.

TREEDATA

Joins a tree's scattered annotation — spread, diameter, height and tree number, each its own piece of text — into one mtext, leaving the spot level exactly where it is.

How to use it

Pre-select, or Select the tree annotation text (window the lot of it): — window whole clusters, as many trees as you like in one go. Each tree becomes one label, starting on the point its first text started:

S:4 D:0.2 H:5
No:3

What it reads

  • S, D and H with a value, however punctuated — S: 4, S4, s 4 all read. Measurements must be numbers.
  • The tree number as No, No. or N — and it may be 3a or 12B, since split trees happen.
  • Values are kept exactly as the surveyor wrote them — 0.20 stays 0.20, because the trailing zero is a statement about precision.
  • The order is whatever the drawing has. H D S is written back as H D S, judged along the line of text so rotated annotation reads correctly too.

What it produces

One mtext per tree — measurements on the first line, the number below — matching the text it replaces for layer, style, height, colour and rotation. The source text is erased in the same step, so one undo takes the whole change back.

Note — Spot levels are never touched. They carry no tag, so the command simply cannot pick them up.
Note — A tree needs its three measurements; the number is optional — unnumbered trees are joined the same and just have no second line, and one never borrows its neighbour's number. Where two trees' text has run together (the same tag twice in one cluster) it says so and leaves them alone — do those few one tree at a time.

EASELEG

Places a schedule of the easements the chosen viewport(s) can actually show — e.g. (A1) EASEMENT TO DRAIN WATER 3 WIDE, one line per designation.

How to use it

Run it on a layout tab (on Model it tells you to switch — the schedule belongs on the sheet). Select viewport(s) for the schedule: — pick one, or as many as you like by picking them in turn, dragging a window over the sheet, or selecting them before you run the command. Either the viewport or its clip boundary works. One viewport scopes the schedule to that viewport, which is usually what a detail wants; several give one combined schedule for the sheet, and an easement showing in two of them is listed once. Then → a dialog lists every designation found and you word each one: pick a standard description, take the suggestion the code letters offer (label an easement (A1) and it proposes EASEMENT TO DRAIN WATER — one click, then type the width), or type your own. Create stays greyed until every designation has wording — the button counts down what's left. Then Schedule insertion point:.

What it produces

A text schedule on the sheet, always in CAPITALS, linked to its viewport. It reads designations from the EASEMENT LABEL layer, so labels placed with EASET, EASEP and EASEARROW all count. A sheet with two details lists only what each viewport shows. The wording is stored in the drawing itself, so a re-issued plan reproduces exactly as drawn.

You can't type into a schedule — it's generated text, so a hand edit is undone and the schedule goes back to saying what the drawing says. Change the wording with EASEDESC instead. If nothing's found, the command says why — how many labels it checked, and how many were at another annotation scale, outside the view, or unlabelled. No ribbon button.

EASELEGUPDATE

Resyncs every placed easement schedule with the drawing.

How to use it

No prompts — it refreshes all schedules and reports how many changed.

Note — with EASELEGAUTO on (the default) you'll rarely need it; it's the manual catch-up for when tracking has been turned off.
Note — a schedule built from several viewports refreshes from all of them. Delete one of those viewports later and the schedule simply shrinks on the next refresh; it only stops tracking when every viewport it was built from is gone.

EASELEGAUTO

Turns live easement-schedule tracking on or off.

How to use it

A toggle — no prompts. The setting is remembered between sessions.

Note — On by default: schedules follow the drawing as you lay a sheet out, so one is never quietly stale. Turn it off if the redraw gets in the way on a heavy sheet.

EASEDESC

Words the drawing's easements without placing or touching a schedule.

How to use it

The same wording dialog as EASELEG, but covering the whole drawing rather than one viewport — so you can describe an easement before the sheet that shows it exists, or fix a description later without placing anything. Placed schedules pick the change up straight away.

Note — designations you've worded before stay editable here even if their label has since been deleted, so a stale entry can always be corrected.

EASEDB

Opens your personal easement description list for editing.

How to use it

No prompts — the list opens in Notepad. One description per line; save, and it's offered next time.

Note — the office standard set (with its code-letter suggestions) ships with the suite; your own additions merge over it. EASEDB edits your personal suggestion list — EASEDESC edits what a particular drawing says.

ADJTXT

Places adjoining-lot text in the office's adjoining style.

How to use it

Sets the ADJOINING LABEL style and the text layer, then places text the usual way.

Note — the adjoining sibling of the lot-text commands. No ribbon button.

HDIM

An aligned dimension for house measurements, with the value in parentheses.

How to use it

Places an aligned dimension; the measurement is written as (12.34).

What it produces

An annotative dimension in the HOUSE DIMENSION style (SMALL LABEL text), created if the drawing doesn't have it.

Note — No ribbon button.

SETBACK

An aligned dimension prefixed SETBACK.

How to use it

Same as HDIM, but the measurement reads SETBACK 6.00.

What it produces

An annotative dimension in the SETBACK style.

Note — No ribbon button.

WTB

Wall-to-boundary: measures between two points and labels the distance along the line.

How to use it

First point: → Second point:. Perpendicular and nearest snaps are turned on for the picks and restored afterwards.

What it produces

Text reading Wall to / Bdy X.XX at the midpoint of the measured line, rounded to the nearest 0.005, in SMALL LABEL on the text layer.

Note — No ribbon button.

NOPLOT

Moves objects to the non-plotting layer.

How to use it

Pre-select and it moves them all at once; otherwise select when asked.

What it produces

The selection lands on NO PLOT with properties ByLayer — visible on screen, absent from the plot.

Note — Handy for construction lines and working notes. No ribbon button.

ROUNDBRG

Rounds bearings in selected text to the nearest 5 seconds — the office survey convention.

How to use it

Pre-select, or Select bearing text to round:. Works on both text and mtext.

Note — Understands both the ° character and the %%d degree code, and writes back whichever the text already used. No ribbon button.

ALAB

Labels each selected lot with its area.

How to use it

Pre-select, or Select polylines to label:. The select prompt also offers Placement, which decides where in the lot the label lands.

What it produces

Area labels on SUB AREA, placed inside each lot. Areas read in m² below a hectare and ha above.

Placement

The same four options are on MTC, and your choice is remembered between sessions.

  • Fit (the default) — the best spot for the size of this label. A label is a wide rectangle, so on a lot wider than it is deep the roomiest point can still let it overhang the frontage; this finds where it actually fits.
  • Roomiest — the point furthest from every boundary.
  • Centre — the true centroid of the lot.
  • Box — the centre of the extents. Predictable, and it lines labels up neatly across a row of similar lots.
Note — Every mode falls back to Roomiest rather than putting a label outside the lot: a centroid lands outside an L-shaped lot, and a long label may fit nowhere.

SETLAYOUT

Builds a complete set of per-lot sales layouts — one sheet per lot, each centred and scaled to its own lot.

How to use it

Select the viewport in your MAIN sales layout: → Enter plot scale denominator (e.g. 200 for 1:200) <200>:. Everything else is automatic.

What it produces

One annotation scale and one layout per lot, each viewport centred on its lot. Tabs are sorted into lot order.

Note — Lot numbers are read as text on the SUB DP layer, so a missing or mis-layered lot number simply won't get a sheet — which makes this a handy QA pass. Pair with INCBLOCK. No ribbon button.

INCBLOCK

Turns each lot into a numbered annotative block that's only visible at its own scale.

How to use it

Enter starting block number <next free number>: then loop: Select lot to block as "N" <exit>:. The annotation scale advances after each lot.

What it produces

A block named after each number containing a copy of the lot, referenced on SUB BDY.

Note — The original lot is left untouched — a copy becomes the block content. Create the named per-lot scales first with CSCALE. No ribbon button.

TADD

Adds a prefix or suffix to selected text.

How to use it

Add text as [Prefix/Suffix] <Suffix>: → Text to add:. Pre-select, or you'll be asked to select afterwards.

Note — Dimensions keep their live measured value, as with TBRK.

LEVTOTXT

Writes surface levels into existing text by picking points.

How to use it

Picks an elevation source first, then loops: Select text: → Select point for level:.

What it produces

Overwrites the picked text with the elevation to one decimal place.

Note — Samples from the drawing's TIN surface, or 3D faces if there's no TIN — so your pick only needs to be right in plan, not snapped to 3D geometry. No ribbon button.

MOFFSET

Offsets a whole selection at once, with a live preview, repeating until you stop.

How to use it

Specify offset distance or [Through/Erase]: — Erase asks whether to delete the sources, Through takes the distance from the cursor. Then select objects and drag to choose the side.

Note — A whole batch offsets consistently — closed shapes all grow or all shrink together. You can type an exact distance mid-drag.

VCOPY

Copies blocks or text to every vertex of the chosen polylines.

How to use it

Pre-select the objects to copy, or you'll be asked. Then Base point: → Select target polylines:.

PIPEL

Turns polylines into pipes — a styled centreline with two wall lines that follow it when you edit.

How to use it

Pre-select, or Select polylines to convert to pipes: → Enter pipe size:.

Note — Edit the centreline and the walls follow; they're locked so they can't be dragged off. The last pipe size is remembered between sessions.

LANDXML

Imports an NSW ePlan / LandXML file — lot boundaries, lot numbers with areas, and monument labels.

How to use it

Opens a file dialog, then Import CgPoints as point entities? [Yes/No] <No>:.

What it produces

Boundaries on the subject or adjoining layers by parcel class, with labels on the matching text layers. Arcs are preserved.

Note — Wide arcs (sweeping over 180°) are flagged on the command line so you can check them against the plan.

TRUNC

Chops decimals off the number in selected text — cutting, not rounding.

How to use it

Pre-select, then Decimal places <2>:.

Note — Only the first number in the text is affected.

RROUND

Rounds the number in selected text — up, down or to nearest.

How to use it

Rounding mode [Nearest/Up/Down]: → Decimal places <2>:.

Note — The rounding mode is remembered between uses.

UPDATE

Fills in title-block attributes across all layouts from a central CSV register.

How to use it

No prompts — it runs from files.

Note — Needs a _DWGLISTCSV.TXT file beside the drawing whose first line names the CSV register. The CSV has the drawing name in the first column, layout name in the second, and attribute tags as the remaining headers.

OB2WO

Turns closed shapes into wipeouts.

How to use it

Pre-select or select circles, ellipses and polylines, then Do you want to keep the original entities? [Yes/No] <Yes>:.

SMT / STRIPMTEXT

Strips all inline formatting out of text, leaving the plain words.

How to use it

Pre-select, or select mtext, leaders, dimensions or blocks with attributes.

Note — Line breaks are kept. Background masks aren't touched — use TBG for those.

LAYREN

Bulk layer rename — add or remove a prefix or suffix, or find-and-replace, across many layers at once.

How to use it

Bulk layer rename — operation: [AddPrefix/AddSuffix/RemovePrefix/RemoveSuffix/Replace] → the text to add, remove or find (Replace also asks Replace with (blank to delete it):) → Apply to layers matching <*>: — a wildcard filter, so SURV* touches only the survey layers.

Note — layer 0 and xref layers are always skipped, and a rename that would collide with an existing name is skipped and reported rather than failing the run. No ribbon button.

SETBYBLOCK

Normalises the entities inside blocks to layer 0 / ByBlock, so the insert's own layer and properties control how the block looks.

How to use it

Pre-select block references, or Blocks to normalise [Select/All] <Select>: (All covers every block definition in the drawing) → Also change entities in nested blocks? [Yes/No] <Yes>:.

What it produces

Every entity inside the chosen block definitions moves to layer 0 with colour, linetype and lineweight set to ByBlock — from then on, changing the insert changes the block.

Note — dynamic blocks are handled through their real definition, so the change survives parameter edits. Xrefs are left alone. Every insert of an edited definition is affected — it changes the block, not one insert. No ribbon button.

WSYUPDATE

Checks for a newer release of the suite and launches the installer.

How to use it

If an update exists: Update to vX? BricsCAD will need to close to finish. [Yes/No] <Yes>:.
