Annotation

Annotation scales and cycling through them.

CSCALE

Creates annotation scales from a dialog, working out the ratio for you.

Ribbon · Annotation → Create New Scale

How to use it

Opens a dialog. Enter the drawing units (the denominator — 200 for 1:200) and a name. The ▾ menu inserts sequence tokens so you can create a run of scales at once:

  • {1-5} — numbers, so Sheet {1-5} makes Sheet 1 … Sheet 5
  • {01-10} — zero-padded numbers
  • {A-E} — letters

Queue scales with +; they're all created when you close the dialog.

What it produces

Named annotation scales using the office convention for metre drawings — 1:200 becomes paper 1, drawing 0.2.

Note — This is the same tool on the BW Engineering ribbon, and builds the named per-lot scales that SETLAYOUT and INCBLOCK rely on.

ANNONEXT / ANNOPREV

Step forward or back through the drawing's annotation scales.

Ribbon · Annotation → Next Scale / Previous Scale

How to use it

No prompts. The new scale is reported on the command line, and the list wraps at both ends.

Note — Scales imported from xrefs are skipped, so cycling stays within the drawing's own list.
