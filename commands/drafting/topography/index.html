Topography

Batters and contour labelling.

BATTER

Fills the space between a top and toe line with batter ticks, each stretched to span the gap.

Ribbon · Topography → Batter

How to use it

Select top batter curve: → Select toe (bottom) batter curve: → then drag to set the tick spacing, with the whole run previewing live. Click to confirm, Esc to cancel.

What it produces

Batter blocks on the BATTER layer, each rotated toward the toe and scaled to span the local gap.

Note — Spacing is adaptive — ticks crowd where the batter narrows. Works on 3D top and toe strings, though the output lands flat.

CONTLAB

Labels a contour with its elevation, sitting the text on the line with a mask through it.

Ribbon · Topography → Contour Label

How to use it

Loops: Select contour <exit>: then drag the label along it. Enter or Esc exits.

What it produces

Masked annotative text on your current layer and style, sitting on the contour so the mask reads.

Note — The elevation comes from the contour's start point.
