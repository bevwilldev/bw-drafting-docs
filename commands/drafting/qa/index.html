QA

The drawing checklist panel.

The QA panel holds a single button. The checklist itself — revisions, the automatic checks and saving a completed pass — is documented under Quality › Drawing Checklist.

OPENCHECKLIST

Opens the project's drawing checklist — the NSW drafting QA form — for the drawing you have open. If the project doesn't have one yet, a copy is made from the master template bundled with the tool.

The checklist lives two folders up from the drawing, in a 4 Checklists folder, matching the office project layout. The window is modeless so you can work in the drawing while it's open, and only one is live at a time.

How to use it

No prompts — run it and the checklist window opens. Warnings appear as message boxes: the drawing not being saved yet, or the bundled master template being missing.

What it produces

Nothing in the drawing. It opens (or creates) Drafting - Drawing Checklist NSW SUR-FO-0615 v1.0.xlsx in the project's 4 Checklists folder.

Note — The button for this sits on the WSY Drafting ribbon's QA panel — there is no button for it on the Engineering, WAE or WSY Tools tabs. Closing a saved drawing that has a project checklist prompts you to complete it first; answering yes opens the checklist modally and holds the close until you're done.
