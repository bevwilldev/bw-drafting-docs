Sheeting

North points and sheet set loading.

ADDNORTH

Drops a north point already rotated to match a viewport's twist.

Ribbon · Sheeting → North Point

How to use it

Select viewport: — then a live preview follows your cursor; click to place. Esc cancels.

What it produces

A North Point block on layer NORTH, annotative, rotated to the viewport's twist angle.

Note — You can pick the viewport's clip boundary instead of its edge — either resolves to the owning viewport.

SSLOAD

Opens this drawing's sheet set, or offers to build one if it doesn't exist.

Ribbon · Sheeting → Sheet Set

How to use it

If a matching .dst sits beside the drawing it opens and saves. Otherwise: No sheet set found for this drawing (name.dst). Create one? [Yes/No] <Yes>: — on Yes it picks a template, adds every paper layout as a sheet, and opens the result.

What it produces

A sheet set named after the drawing, in the drawing's folder.

Note — Requires a saved drawing with at least one paper layout. The template is chosen from the drawing's filename suffix — DP/SP/CP/PP use the plan form template, SET/ID/FW/PEG the setout template, SAL/LOT the lot template, anything else the detail template.
