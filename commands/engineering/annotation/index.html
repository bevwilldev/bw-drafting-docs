Annotation

BW standard text heights, matching multileaders and the dimension wrappers.

BW25

The smallest of the four BW text heights, for general notes and callouts on engineering plans. Like the rest of the family it does double duty: it places new text, and it reformats text you already have to the standard.

How to use it

Select the text first and it's reformatted in place — single-line text is converted to MText on the way. Run it with nothing selected and it loops, prompting Text insertion point [ESC to exit] and opening the in-place editor at each point until you press Esc. Empty results are discarded.

What it produces

Annotative MText in the BW_AN style on layer T25 (yellow), colour ByLayer, line spacing 0.8 at-least. The height is the drawing's TEXTSIZE — set to 2.5 by this command — divided by the current annotation scale value. Reformatted text is attached middle-centre; newly placed text is attached top-left.

Note — Set the right annotation scale before you place text — the height is derived from it.

BW35

The 3.5 mm step of the BW text family — the usual choice for sub-headings and labels that need to read above general note text.

How to use it

Select the text first and it's reformatted in place — single-line text is converted to MText on the way. Run it with nothing selected and it loops, prompting Text insertion point [ESC to exit] and opening the in-place editor at each point until you press Esc.

What it produces

Annotative MText in the BW_AN style on layer T35 (green), at a working TEXTSIZE of 3.5 divided by the current annotation scale value.

BWDIMALI

The aligned equivalent of BWDIMLIN — the dimension line runs parallel to the two points rather than orthogonally.

How to use it

Run the command and the native DIMALIGNED prompts follow — pick the two points, then place the dimension line.

What it produces

An aligned dimension on layer DIMS in the BWAN_DIM25 style.

BWDIMANG

Dimensions the angle between two lines, or the included angle of an arc or circle, with the BW layer and style already set.

How to use it

Run the command and the native DIMANGULAR prompts follow — pick the two lines (or the arc), then place the dimension arc.

What it produces

An angular dimension on layer DIMS in the BWAN_DIM25 style. Angular decimal places are set to 0 in that style.

BWDIMARC

Dimensions the length along an arc rather than the chord — used on kerb returns and curved alignments.

How to use it

Run the command and the native DIMARC prompts follow — select the arc or polyline arc segment, then place the dimension.

What it produces

An arc length dimension on layer DIMS in the BWAN_DIM25 style.

BWDIMDIA

Labels the diameter of a circle or arc — typically pipes and pits — with the BW layer and dimension style already set.

How to use it

Run the command and the native DIMDIAMETER prompts follow — select the circle or arc, then place the dimension text.

What it produces

A diameter dimension on layer DIMS in the BWAN_DIM25 style.

BWDIMLIN

A wrapper around the native DIMLINEAR that sets the DIMS layer and the BW dimension style first, so you never have to remember to switch either.

How to use it

Run the command and the normal linear dimension prompts follow — pick the two extension line origins, then place the dimension line.

What it produces

A linear dimension on layer DIMS (white) in the BWAN_DIM25 style: 2.5 mm yellow text in BW_AN, 2.5 mm closed filled arrows, two decimal places, text above the dimension line, and annotative.

BWDIMRAD

Labels the radius of a circle or arc with the BW layer and dimension style already set.

How to use it

Run the command and the native DIMRADIUS prompts follow — select the circle or arc, then place the dimension text.

What it produces

A radius dimension on layer DIMS in the BWAN_DIM25 style.

BWML25

Places a multileader whose text height, arrow size and dogleg all match the 2.5 mm BW text standard, so a leader note sits alongside BW25 text without looking out of scale.

How to use it

Run the command and the native MLEADER takes over — pick the arrow point, then the landing, then type the text.

What it produces

A multileader on layer T25 using the BWAN_ML25 style: straight leader, dogleg enabled at 2.5, 2.5 mm arrow, annotative MText content in BW_AN at 2.5 mm, leader and text colour ByLayer, landing gap 1.5, attached to the middle of the top line and held horizontal. The style is made current (CMLEADERSTYLE).
