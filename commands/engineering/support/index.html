Support

The Support panel sits at the start of every ribbon tab — one button now: Ask Caddie, with Docs and Report a Bug in its dropdown.

CADDIE

Opens Caddie, the documentation assistant, in a dockable panel beside the drawing — the ribbon's Ask Caddie button. Ask what a command does, what it prompts for, or why something has stopped working — in your own words, with follow-ups.

How to use it

Type a question and press Enter. Answers come from this documentation and end with links to the pages they came from. Closing the panel keeps the conversation; it is there when you reopen it.

Note — Caddie is told nothing about your drawing: not the file name, not a layer, not a selection. His entire knowledge is this site, so anything job-specific is beyond him — deliberately.

ENGHELP

Opens the engineering documentation in your browser — the ribbon's Help button.

How to use it

No prompts. If the browser can't be opened it says so on the command line.

ENGBUG

Opens the Support & Requests form — the ribbon's Report a Bug button.

How to use it

No prompts. Use it for anything odd, and for tool ideas too: the form asks what kind of request it is and only shows the relevant questions.

Note — Reports go straight to the Western Sydney Drafting team. While the suite is in early access this is the main feedback channel, and fixes usually reach you automatically within a day or two.
