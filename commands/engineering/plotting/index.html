Plotting

A1 and A3 PDF output, and A3 printing.

BWPDFA1

One-click PDF of the sheet you're looking at, at full A1 size. It drives the native -PLOT command with a fixed token stream, so there is nothing to set up and nothing to get wrong.

How to use it

Open the layout you want and run the command — there are no prompts. When the plot finishes the PDF is opened for you.

What it produces

A PDF written to your Documents folder, named drawing-layout.pdf after the drawing and the current layout, plotted through Print as PDF.pc3 on A1 media, millimetres, landscape, extents, centred, at 1:1.

Note — Paper space only — in model space it says This function can only be used in paper space. and stops. If the Print as PDF.pc3 device isn't installed it refuses to start rather than half-plotting, and tells you to reinstall the suite. If you cancel the plot, or the PDF doesn't appear where it was expected, it says so on the command line instead of opening anything.

BWPDFA3

The half-size check print of the same sheet — an A1 layout reduced to A3. Used for markups and issue copies.

How to use it

Open the layout you want and run the command — there are no prompts. When the plot finishes the PDF is opened for you.

What it produces

A PDF written to your Documents folder, named drawing-layout.pdf, plotted through Print as PDF.pc3 on A3 media, millimetres, landscape, extents, centred, at 1:2.

Note — Paper space only, and it needs the Print as PDF.pc3 device — same conditions as BWPDFA1.

BWPRINTA3

Sends the sheet you're on straight to the survey room printer at A3, without going through the plot dialog.

How to use it

Open the layout you want and run the command — there are no prompts. A message box confirms The layout "…" has been printed to "WSY-SurveyRoom". when it's done.

What it produces

A hard copy through the WSY-SurveyRoom.pc3 device on A3 (297 × 420 mm) media, millimetres, landscape, extents, centred, at 1:2. Nothing is added to the drawing.

Note — Paper space only. If the device isn't installed the command stops before sending anything, and if the plot is cancelled or fails you get a command-line message rather than the confirmation dialog.
