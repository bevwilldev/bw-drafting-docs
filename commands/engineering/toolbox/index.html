Toolbox

Shared tools that ride with every plugin in the suite.

ATC

Aligns new or existing text to a polyline, arc, spline or multileader by dragging it along the target — the text rotates to follow the curve as you move, and you click to drop it. It's the tool for labelling pipes, alignments and boundaries where the label has to sit on the line.

The same drag machinery is shared with the drafting ribbon's CLABEL, and the settings dialog is common to both.

How to use it

It loops until you exit. At Select text to align [New/Settings] <Exit>: pick existing text or mtext, choose New and answer Specify text <select>: to create some, or choose Settings to open the dialog. Then Select curve or multileader to align to: — curves nested inside blocks and xrefs are valid targets. Drag the text into place and click. Esc or Enter at the first prompt exits.

The dialog controls the object type for new text (text or mtext), justification, offset factor, rotation, readable orientation, background mask and its offset, plus Multiple and Copy modes and the layer and text style used for new text. Settings persist between sessions.

What it produces

Moves and rotates the text you selected, or creates new text or mtext using the type, justification, layer and style set in the dialog. With Copy selected on, the original is left alone and a copy is placed; with Multiple on, it keeps dragging a fresh copy after each click.

Note — Cancelling a drag restores the original text rather than leaving it half-moved. Text on a locked layer is reported as not editable and skipped.

OB2WO

Turns circles, ellipses and polylines into wipeouts. The native wipeout command only accepts straight-segment polylines, so this samples curved geometry into enough vertices to keep the shape.

How to use it

Select the objects first if you like, otherwise it asks for a selection filtered to circles, ellipses and polylines. Then Do you want to keep the original entities? [Yes/No]:, defaulting to Yes.

What it produces

One wipeout per valid object, on the current layer. Circles and ellipses are sampled at 50 points; polyline arc segments at 1 + 25 × √|bulge| points. It reports Wipeouts created for the selection set (N).

Note — Objects that can't be sampled into at least three points are silently skipped.

OUTLINE

Traces the outline around a set of objects. It builds a temporary rectangular frame just outside the selection's extents and then uses the native BOUNDARY command to construct outlines around every island inside that frame.

This is Lee Mac's Outline Objects routine, carried in the suite's Community LISP tools component rather than compiled into the plugin.

How to use it

Select the objects to outline, then answer Erase original objects? [Yes/No] <Yes>: — the default erases them and leaves only the outline.

What it produces

One or more closed polylines or regions on the current layer, following whatever the native BOUNDARY command produces for the selection.

Note — Requires the Community LISP tools component to be installed; without it the command isn't defined.

SMT

Removes every inline formatting code — colour, font, height, width, oblique, tracking, underline, overline, alignment and paragraph codes, plus stacked fractions and grouping braces — leaving plain content that picks up its appearance from the text style.

It is a no-dialog strip-everything command by office preference. STRIPMTEXT is registered as an alias and does exactly the same thing.

How to use it

Select the objects first if you like, otherwise it asks for a selection filtered to mtext, multileaders, dimensions and block references. There are no further prompts; it reports StripMtext completed. N objects processed.

What it produces

Rewrites the contents of mtext, multileader mtext content, dimension text overrides and block attribute values. Mtext columns are collapsed so the text reflows as one block.

Note — Line breaks (\P) are kept — they are content, not formatting — as are escaped literals. Stacked fractions become readable a/b text. Background masks are a property rather than an inline code, so they are left alone.

TADD

Bulk-edits a selection of annotation by putting the same string in front of or behind each item — adding units, an approx. qualifier or a diameter symbol across a set of labels in one go.

How to use it

Select the entities first if you like. It asks Add text as [Prefix/Suffix], defaulting to Suffix, then Text to add: (spaces allowed). If nothing was pre-selected you're then asked to Select text entities:, filtered to text, mtext and multileaders. An empty string cancels.

What it produces

Edits the existing entities in place; nothing is created.

Note — For dimensions, a measurement with no override is represented as the <> placeholder so a prefix or suffix keeps the live measured value rather than freezing it. The engineering and drafting plugins both carry this command; the implementations are identical, so having both installed is harmless.

VPO

Constructs a polyline in model space representing what a paper space viewport actually shows, accounting for the viewport's position, scale, rotation and view direction. Useful for checking coverage before issuing a sheet set, or for building a key plan.

This is Lee Mac's Viewport Outline routine, carried in the suite's Community LISP tools component. Two variants come with it: VPOL outlines every viewport in the active layout, and VPOA every viewport in every layout.

How to use it

Switch to a layout with no viewport active, then run it and answer Select viewport:. In model space it refuses with Command not available in Modelspace.

What it produces

A 2D (LW) polyline in model space tracing the transformed viewport boundary. Rectangular, polygonal and clipped viewports are all handled, including arc segments.

Note — Requires the Community LISP tools component. The polyline's properties and optional interior offset are fixed in that routine's own parameters section.
