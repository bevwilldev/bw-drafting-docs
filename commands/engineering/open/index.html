Open

Titleblock update, the drawing register and the job folder.

DIROPEN

Opens the folder the active drawing lives in — handy for grabbing a reference, checking the rasters folder or dropping a PDF next to the DWG.

How to use it

No prompts — run it and Explorer opens at the drawing's folder.

What it produces

Nothing in the drawing.

Note — The drawing has to have been saved; an unsaved drawing has no folder and you'll get Drawing folder not found (unsaved drawing?).

EXCELREG

A shortcut to the register that sits beside the drawings, so you don't have to go looking for it in Explorer.

How to use it

No prompts — run it and the register opens. It looks in the current drawing's folder for the first file matching *_Drawing_Register.xls*, so both .xls and .xlsx registers are found.

What it produces

Nothing in the drawing — it opens the spreadsheet in whatever application is registered for it.

Note — The drawing has to have been saved. If the folder can't be resolved you get Drawing folder not found (unsaved drawing?)., and if there's no register beside it, File not found.

UPDATE

Fills in every title block in the drawing from a shared CSV, so a project's sheet numbers, titles, dates and revisions are maintained in one spreadsheet rather than sheet by sheet.

The drawing folder holds a pointer file, _DWGLISTCSV.TXT, whose first line names the CSV. In the CSV the first column is the drawing name, the second is the layout, and every remaining column heading is an attribute tag.

How to use it

No prompts — run it and it reports either --> Attributes are up-to-date. or --> N attributes updated in N blocks. Everything else it has to say is a diagnostic: the pointer file being missing or empty, the CSV not being found, the file not being a .csv, or this drawing's name not appearing in the first column.

What it produces

Changes attribute values on block references in the layouts named in the CSV. Only attributes whose tag matches a column heading and whose value actually differs are touched; nothing is created or erased.

Note — Drawing names and layout names are matched case-insensitively, and the drawing name is compared without its extension. The CSV is read using the machine's regional list separator, falling back to a comma.
