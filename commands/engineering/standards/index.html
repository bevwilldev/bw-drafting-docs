Importing the BW style set and managing annotation scales.

BWSCALES

Replaces whatever annotation scales a drawing has accumulated with the office engineering list — the plain ratios plus the named layout scales used on engineering plan sets.

It is deliberately a manual command and never runs on its own, because it wipes the list before rebuilding it.

How to use it

No prompts and no confirmation. It runs immediately and reports how many scales it removed and added — Scale list reset: N removed, N added.

What it produces

The named presets Layout Plan, Line Marking, Intersection Detail, Parking Plan, Turning 500 / 250 / 200, Sewer Layout, Water, MD Locality and MD Layout, plus the ratio scales 1:10000, 1:5000, 1:2500, 1:2000, 1:1000, 1:500, 1:250, 1:200, 1:100, 1:50, 1:25, 1:20 and 1:10. Scales that already exist by name are left alone.

Note — Every other scale is removed first. The currently active scale is skipped, and any scale still referenced by annotative objects can't be deleted so it survives — but anything else you had added is gone.

BWSTYLEIMPORT

Seeds a drawing with the Beveridge Williams standard styles so the engineering annotation commands have everything they need. It is the first thing to run in a drawing that didn't come from a BW template.

The styles are created on demand and the full specification is re-applied every time, so a style that an older build made wrongly is repaired the next time the command runs.

How to use it

No prompts — run it and the styles are added. It reports [WSYDrafting] BW styles imported (BW_AN family, BWAN_DIM25/35). on the command line when it's finished.

What it produces

The BW_AN text-style family — BW_AN (arial narrow, annotative), BW_AN_Italics (arial italic), BW_BK_Lotno (arial black) and BW_AU (arial unicode ms) — plus the BWAN_DIM25 and BWAN_DIM35 annotative dimension styles.

Note — Whatever text style, TEXTSIZE and dimension style were active before you ran it are restored afterwards, so importing the styles never changes what you're currently drawing with.

CSCALE

Adds annotation scales one at a time or in batches, using the office convention for metre drawings: paper units are fixed at 1 and the drawing units are the denominator divided by 1000.

This is the same tool as the Add New Scale button on the WSY Drafting ribbon — it ships in the shared toolbox assembly, so both ribbons run exactly the same command.

How to use it

Opens a dialog rather than prompting on the command line. Enter the drawing units and a name (which auto-fills to the ratio), and add as many as you need before closing. It reports N scale(s) created.

What it produces

Annotation scale entries in the drawing's scale list. Nothing is drawn. A scale whose name already exists is skipped rather than duplicated.

Note — Scales that arrived through an xref are hidden from the existing-names list — BricsCAD suffixes them _XREF and AutoCAD-style names contain an @. The older prompt-based BWCSCALE has been retired; use CSCALE.
