Point Cloud Digitizer

Traces features off a point cloud — step along at a fixed distance per vertex, or trace freely — with each vertex snapped to the cloud, numbered and coded as you go.

Opening it

Run PCDIG, or use the button on the WSY Tools ribbon tab. Each drawing gets its own panel. The ? button in its title bar opens offline help.

Setting up

SettingWhat it does
Fixed-distance steppingThe checkbox beside Segment Dist. With it on, each new vertex lands exactly the segment distance from the last in the direction you pick, and a guide circle shows that distance. Turn it off to trace freely — you click each vertex where you like and the distance field greys out.
Segment distanceHow far each new vertex lands from the last while stepping. Read live — change it mid-string and the next segment uses the new value.
Enable point creationPlaces a survey point at each vertex as well as the line. Uses Civil points where available (the label reads Civil or Standard to show which).
Start numberThe first point number. Auto-fills past anything already used; the ↻ button finds the lowest free number.
Point codeThe feature code written onto the points and string.
LayerSet manually, or automatically from the code library.

Using a code library

Browse to a Trimble .fxl feature library with the … button. Once loaded, the point code becomes a searchable picker, and the layer and colour come from the selected feature automatically. The ✕ button unloads it.

Note — the library isn't remembered between sessions; browse to it again when you reopen the drawing.

Digitising

  • Add Line — pick a start point, then pick a direction for each following point. A guide circle shows the fixed distance. Undo steps back a point; Esc finishes the string.
  • Add Point — places standalone points without a line. Undo steps back; Esc finishes.
  • Extend — select an existing 3D polyline near the end you want to continue from.

While digitising, ordinary 2D snaps are turned off and point-cloud snapping is turned on, then restored when you finish.

Exporting to 12d

Export to 12da… writes every digitised string and point to a 12d Model ASCII file. Points sitting on a string vertex aren't duplicated. Colours come from the code library where one is loaded.

Note — the export scans model space only, and can't run while a digitising run is active.
