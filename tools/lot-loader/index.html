Map Data

One panel for the site: choose the area once, tick the data you want — lot boundaries, labels, road names — and fetch it all in one pass. Replaces the old three-tab NSW Lot Loader panel; every NSWLOTS command still works.

Opening it

Run MAPDATA (or the older NSWLOTS), or use the Map Data button on the WSY Tools ribbon tab. The panel stays open while you work. The ? button in its title bar opens offline help.

Choosing the area — once

The area at the top of the panel applies to every ticked layer, so a rectangle is only ever picked once:

ModeWhat it does
Subject lotsFind lots by plan number — up to ten rows of DP/SP plan (required) with optional lot and section. This is the site itself; neighbours come along per the Lot boundaries options. Unmatched entries are flagged on the command line.
Around a pointPick a location in the drawing; everything within the buffer radius is fetched (up to 5000 m).
RectangleYou pick the two corners when you press Fetch — the panel gets out of the way first.
Current viewUses whatever the drawing window currently shows.

Data layers — pick and choose

Each row fetches independently and reports its own result on the row itself — 12 subject, 34 adjoining lot(s), No roads found. — so a half-empty fetch can never pass for a full one. Options grey out while their row is unticked.

Layer rowWhat you get
Lot boundariesBoundary polylines — subject lots on SUB BDY, adjoining/surrounding on ADJ BDY. In Subject lots mode, Adjoining lots fetches the neighbours and Surrounding within extends to a radius (0 = adjoining only).
Lot labelsLot/plan text inside each fetched lot — subject labels on SUB DP, adjoining on ADJ DP. Adjacent only labels lots sharing a boundary with a subject lot; All labels everything fetched.
Road namesRoad name text on ROAD NAME, oriented along the centreline; optionally the centreline geometry on ROAD CL.
Aerial imageryA georeferenced site photo over the same area, attached behind the linework on the non-plotting AERIAL IMAGE layer — with source choice, Nearmap survey-date picking and a preview. This row only exists on machines with the Aerial Imagery plugin; it is not part of the standard install.
Watch out — aerial imagery is licensed for internal reference only. It attaches on a non-plotting layer and must not appear on issued sheets. The drawing must be saved first — the image file is stored beside it in an Aerial folder.
Watch out — the tool works out the MGA zone from the data it fetches. If it can't determine the zone it assumes Zone 56 and says so. On a Zone 55 job that warning matters, so check the result lands where you expect.

Labelling loaded lots

NSWLABELLOTS labels lots that were loaded earlier — select the boundaries and it reads the plan details stored on them.

Watch out — it doesn't check whether a lot is already labelled. Running it twice over the same selection stacks a second set of labels on top of the first, which is easy to miss on screen. Undo rather than trying to pick the duplicates out.

Updating and removing fetched data

MAPDATAUPDATE refreshes the cadastre: it removes every vector entity the tool has drawn, then re-runs your last saved search so the geometry matches what NSW Spatial holds today. The aerial image is deliberately not re-fetched — cadastre goes stale, a dated capture doesn't — tick Aerial imagery and press Fetch when you want a fresh photo.

MAPDATADELETE removes everything the tool put in the drawing — boundaries, labels, road names, centrelines, the attribution stamp and aerial images — and reports what it took out. Your own work on the same layers is never touched: removal goes by the tags the tool wrote, never by layer. The imagery JPG files beside the drawing stay on disk. Undo brings it all back.

NSWLOTSUPDATE and NSWLOTSDELETE keep working as before (vectors only).

Watch out — lot labels placed by versions before v2.3, and aerial images attached before tagging existed, carry no tag and are left behind. Delete those by hand if they turn up.

When a fetch only half works

If some features can't be drawn, the panel says so — Drew 47 of 50 feature(s), with the first reason — and asks whether to keep what was drawn or discard it. Discard is the default: a drawing missing cadastre it appears to have is worse than no cadastre at all, and the fetch can just be run again. Discard removes only what that fetch added — anything already in the drawing is untouched. Imagery fetches only after the review passes, so a discarded fetch never leaves a photo behind.

Lots skipped because they were already loaded aren't failures and are never reported as such.

Activity log

Each fetch, delete and label run writes one line — the command, the drawing and the counts — to %LOCALAPPDATA%\BW BricsCAD Tools\drawing-audit.log, so "what did that command do to my drawing?" can be answered days later when the question actually gets asked. The same log covers TREEDATA, CURVETABLE, EASELEG, SETLAYOUT and IMPORTSHEET. Counts only: nothing about the drawing's content is recorded, and nothing leaves your machine.

Data attribution

The cadastre comes from NSW Spatial Services under the CC BY 4.0 licence, which makes attribution in the drawing a licence condition — so each fetch places (or refreshes) one attribution stamp on the ATTRIBUTION layer. Move it to wherever suits the sheet; a later fetch updates its wording in place without moving it back. Just leave it in the drawing.

If it fails

The tool needs internet access to the NSW Spatial service. Transient errors are retried automatically; a persistent failure is reported in the status bar. Large extents can take a while — the Cancel button stops a fetch cleanly.
