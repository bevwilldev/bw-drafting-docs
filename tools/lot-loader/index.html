NSW Cadastral Lot Loader

Pulls lot boundaries, labels and road names straight from NSW Spatial into model space — by lot and plan number, by a point, or by an extent.

Opening it

Run NSWLOTS, or use the button on the WSY Tools ribbon tab. The panel stays open while you work. The ? button in its title bar opens offline help.

Import options

These control what gets labelled and whether road data comes in:

OptionEffect
Subject Lot LabelsLabels the lots you asked for (the By Lot ID search only).
Adjoining Lot LabelsLabels neighbouring lots. Adjacent only labels just those sharing a boundary; All also labels the surrounding buffer. On the By Point and By Extent searches this labels everything returned.
Road NamesPlaces road name text along each centreline.
Road CentrelinesAlso draws the centreline geometry.

Three ways to search

By Lot ID

Enter the plan number (required) and optionally the lot and section, choosing DP or SP. Add more rows with + for multiple lots (up to ten), then click Fetch Lots. The Buffer is how far around each lot to fetch surrounding lots — set 0 for adjoining only (up to 5000 m). If an entry matches nothing, it's flagged on the command line so you can check the lot and plan.

By Point

Click Pick Point, pick in the drawing, set the buffer radius, then Fetch Lots — every lot within that radius is fetched.

By Extent

Choose Current View or Draw Rectangle, then Fetch Lots.

What you get

LayerContents
SUB BDYSubject lot boundaries
SUB DPSubject lot labels
ADJ BDYAdjoining and surrounding boundaries
ADJ DPAdjoining labels
ROAD NAMERoad name text, rotated along the centreline
ROAD CLRoad centrelines

The By Lot ID search separates the lots you asked for (SUB layers) from their neighbours (ADJ layers); the By Point and By Extent searches load everything onto the ADJ layers. Re-running never doubles up — lots already loaded are skipped. Your entries and settings are remembered for next time.

Labelling loaded lots

NSWLABELLOTS labels lots that were loaded earlier — select the boundaries and it reads the plan details stored on them.

Watch out — it doesn't check whether a lot is already labelled. Running it twice over the same selection stacks a second set of labels on top of the first, which is easy to miss on screen. Undo rather than trying to pick the duplicates out.
Watch out — the tool works out the MGA zone from the data it fetches. If it can't determine the zone it assumes Zone 56 and says so in the status bar. On a Zone 55 job that warning matters, so check the result lands where you expect.

If it fails

The tool needs internet access to the NSW Spatial service. Transient errors are retried automatically; a persistent failure is reported in the status bar. Large extents can take a while — the Cancel button stops a fetch cleanly.
