Support & Requests

Found a bug, want a new tool, or is something not behaving the way you'd expect? Send it through here — it goes straight to the Western Sydney Drafting team.

Before you submit

Two quick checks that resolve a good share of reports:

  • Make sure you're on the latest version. Type WSYUPDATE in BricsCAD — if there's a newer build it will offer to install it. A fair few reported problems are already fixed in a later release.
  • If a ribbon or command is missing, run through Troubleshooting first — it covers the usual causes (wrong profile, component not installed).

You don't need all of this, but the more you can give, the faster it gets sorted:

Ideas are just as welcome as bugs. If there's a repetitive job you do by hand that the toolset could do for you, say so — most of this suite started as exactly that kind of request.

What happens next

  • Your request lands with the Western Sydney Drafting team and gets triaged.
  • Fixes and new tools ship in a suite release — you'll get the update notice inside BricsCAD when one is ready.
  • What changed in each version is listed on the releases page.
