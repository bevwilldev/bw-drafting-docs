Horizontal & Vertical Text

Quick WAE text at a fixed rotation, for annotating rotated sheets without fighting the UCS.

Commands

  • HTXT — horizontal text at 0°.
  • VTXT — vertical text at 270°.

Using them

Run the command, then Text insertion point:. Type the text in place and finish as normal. Because the WAE label style has a fixed height you're not asked for one.

What it produces

MText on the ANNOTATIONS layer (colour 10) in the WAE LABEL style — Lucida Sans Unicode at a fixed 2.5 mm.

The style is not annotative, unlike the drafting and engineering text commands. WAE plans are worked at paper scale, so the height is fixed rather than following the drawing's annotation scale. Layer and style are created on demand if they're missing.

Note — it places the text at a fixed angle regardless of the drawing's current angle base.
