Utilities

Offsetting, copying to vertices, pipes, imports and text number tools. Mostly command-line only.

Drawing tools

MOFFSET

Offsets a whole selection at once, with a live preview, repeating until you stop.

How to use it

Specify offset distance or [Through/Erase]: — Erase asks whether to delete the sources, Through takes the distance from the cursor. Then select objects and drag to choose the side.

Note — The curve nearest your cursor decides the side, and other closed shapes follow the same sense — so a batch of lots all shrink or all grow together rather than splitting. You can type an exact distance mid-drag.

VCOPY

Copies blocks or text to every vertex of the chosen polylines.

How to use it

Pre-select the objects to copy, or you'll be asked. Then Base point: → Select target polylines:.

PIPEL

Turns polylines into pipes — a styled centreline with two wall lines that follow it when you edit.

How to use it

Pre-select, or Select polylines to convert to pipes: → Enter pipe size:.

Note — The walls stay associated with the centreline: edit the centreline and they follow. They're deliberately locked so they can't be dragged off. The last size is remembered between sessions.

Import

LANDXML

Imports an NSW ePlan / LandXML file — lot boundaries, lot numbers with areas, and monument labels.

How to use it

Opens a file dialog, then Import CgPoints as point entities? [Yes/No] <No>:.

What it produces

Boundaries on the subject or adjoining layers by parcel class, with labels on the matching text layers. Arcs are preserved.

Note — Two data-quality guards: a curve whose geometry is inconsistent degrades to a straight chord rather than a wild arc, and arcs sweeping over 180° are redrawn as the minor arc and reported so you can check them against the plan.

Text numbers

TRUNC

Chops decimals off the number in selected text — cutting, not rounding.

How to use it

Pre-select, then Decimal places <2>:.

Note — Only the first number in the text is affected.

RROUND

Rounds the number in selected text — up, down or to nearest.

How to use it

Rounding mode [Nearest/Up/Down]: → Decimal places <2>:.

Title blocks

UPDATE

Fills in title-block attributes across all layouts from a central CSV register.

How to use it

No prompts — it runs from files.

Note — Needs a _DWGLISTCSV.TXT file beside the drawing whose first line names the CSV register. The CSV has the drawing name in the first column, layout name in the second, and attribute tags as the remaining headers.

OB2WO

Turns closed shapes into wipeouts.

How to use it

Pre-select or select circles, ellipses and polylines, then Do you want to keep the original entities? [Yes/No] <Yes>:.

SMT / STRIPMTEXT

Strips all inline formatting out of text, leaving the plain words.

How to use it

Pre-select, or select mtext, leaders, dimensions or blocks with attributes.

Note — Line breaks are kept — they're content, not formatting. Background masks aren't touched; use TBG for those.

WSYUPDATE

Checks for a newer release of the suite and launches the installer.

How to use it

If an update exists: Update to vX? BricsCAD will need to close to finish. [Yes/No] <Yes>:.
