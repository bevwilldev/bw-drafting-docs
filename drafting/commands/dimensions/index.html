Dimensions & Curve Tables

Automatic boundary dimensioning, numbered curve labels, and the curve schedule that reads from them.

None of these have a ribbon button — they're typed at the command line. This is the largest and most useful part of the toolset that's easy to miss.

The workflow

These commands are designed to run in sequence:

  1. AUTODIM dimensions every boundary segment and drops a numbered label on each curve.
  2. DIMRENUM tidies the numbering if you've edited things.
  3. CURVETABLE builds a schedule from those numbered labels.
  4. CURVETABLEUPDATE resyncs the table after further edits.

Dimensioning

AUTODIM

Dimensions every segment of the selected lot boundaries in one hit — length inside, bearing outside, and a numbered label on each curve.

How to use it

Pre-select, or Select polylines/arcs:. Then Enter precision <3>: → Include bearings? [Yes/No] <Yes>: → Starting curve number: (defaults to this drawing's highest existing label plus one).

What it produces

Lengths on SUB DIMENSIONS, bearings on SUB BEARINGS, and a Dimension Label block on DIM LABEL for each arc carrying its chord, arc, radius and bearing as hidden attributes.

Note — Several behaviours worth knowing. For a closed lot, dimensions go inside and bearings outside. A boundary shared between two lots is dimensioned once, not twice. Existing labels are never doubled up, so re-running after edits only fills the gaps. Collinear runs merge into one stretched bearing. Segments it can't dimension are counted and reported rather than hidden.

DIMLAB

Places numbered dimension-label bubbles, or converts existing text into them.

How to use it

Pre-select text to convert it. Otherwise Specify starting number: then place them one at a time; the number increments as you go.

What it produces

Dimension Label blocks on DIM LABEL.

Note — Numbering continues from the highest number already in the drawing and skips any number already in use. The whole run is one undo step.

DIMRENUM

Renumbers dimension labels in sequence, closing gaps left by deleted ones.

How to use it

Pre-select, or Select dimension labels to renumber: → Starting number <1>:.

Note — Existing relative order is preserved — labels are sorted by their current number, so renumbering closes gaps without shuffling things around.

Curve tables

CURVETABLE

Builds a schedule of curved dimensions from the numbered curve labels, or exports them to CSV.

How to use it

In model space: pre-select, or Select dimension label blocks or Enter for all:. In a layout: it asks you to Select viewport: and includes only the labels visible in it.

Then N curves — specify table insertion point or [Export]:. Export writes a CSV.

What it produces

A table titled Schedule of Short & Curved Dimensions on the TEXT layer, with columns for number, bearing, chord, arc and radius, sorted numerically.

Note — Viewport scoping is the subtle part: a label must both carry that viewport's annotation scale and fall inside its boundary — respecting a non-rectangular clip if there is one. If nothing qualifies, the message tells you exactly what was rejected and why.

CURVETABLEUPDATE

Resyncs a placed curve table with the drawing — adds new curves, drops deleted ones, refreshes changed values.

How to use it

Select curve table to update or Enter to refresh all:.

Note — Only works on tables created by CURVETABLE. The table keeps the size it was created at, so it won't jump around if you've changed annotation scale.

CURVETABLEAUTO

Turns live curve-table refreshing on or off.

How to use it

A toggle — no prompts. The setting is remembered between sessions.

Note — Off by default. When on, linked tables refresh shortly after you stop editing. The refresh doesn't add undo steps.

DIMDATA

The inverse of CURVETABLE — reads a hand-drawn or imported curve schedule and writes its values back into the matching numbered labels.

How to use it

Pre-select, or Select the curve schedule text (window the whole table):.

Note — Built for surveyor DXF exports. It reconstructs the table from the text positions, using a header row if one is present, otherwise assuming the standard No / Bearing / Chord / Arc / Radius order.

ALAB

Labels each selected lot with its area.

How to use it

Pre-select, or Select polylines to label:.

What it produces

Area labels on SUB AREA, placed inside each lot. Areas read in m² below a hectare and ha above.
