Survey Commands

Pegs, reference marks, survey marks, ties and traverse lines.

Marks and symbols

PEG

Drops peg symbols, either one at a time or on every vertex of chosen polylines.

Ribbon · Survey → Peg

How to use it

Select polylines first and a peg is placed on every vertex. Otherwise: Specify insertion point or [Place]: — pick points one at a time, or type Place to select polylines instead. Endpoint snap is forced on.

What it produces

Peg blocks on layer PEG, annotative and attached to the current scale.

Note — Vertex mode skips any vertex that already has a block, so re-running is safe.

REF

Places reference marks, or swaps existing blocks for reference marks in place.

Ribbon · Survey → Reference Mark

How to use it

Specify insertion point or [Replace]:. Replace loops asking for blocks to swap; each is erased and a reference mark inserted at its position.

What it produces

Reference Mark blocks on SURV REFERENCE, annotative.

Note — Replace keeps only the position — rotation and attributes of the old block are discarded.

SURVSSM

Places SSM (state survey mark) symbols in a loop.

Ribbon · Survey → SSM

How to use it

Loops Specify insertion point: until you press Enter or Esc.

What it produces

SSM blocks on SURV SSM MARK, annotative.

SSMX / SSMY

Place a single 'X' or 'Y' mark symbol.

Ribbon · Survey → 'X' Symbol / 'Y' Symbol

How to use it

One prompt: Specify insertion point:. Single shot — these don't repeat.

What it produces

X or Y blocks on SURV SSM MARK.

Lines

TIEL

Draws a tie line between two points, labelling the distance on one side and the bearing on the other.

Ribbon · Survey → Ties

How to use it

Specify base point for leader: → Specify second point for leader:, with endpoint, intersection and perpendicular snaps forced on.

What it produces

A dashed leader on SURV TIES plus two labels on SURV TIES TEXT. Distance is rounded to the nearest 0.005; the bearing reads to the nearest 5 seconds.

TRAVL

Draws a traverse line — a dashed annotative leader with no text.

Ribbon · Survey → Traverse

How to use it

Runs the native MLEADER command.

What it produces

Layer SURV TRAVERSE with the condensed linetype scale.

Occupations

OSFCE

Draws an occupation fence line using the fence linetype.

Ribbon · Occupations → Fence

What it produces

Layer SURV OCCS with the Fence linetype.

Note — Needs the Support linetype file. If the fence draws solid, the linetype didn't load — see Troubleshooting.

BDYFCE

Boundary fence tick line.

Ribbon · Occupations → Fence Ticks

What it produces

Layer SURV OCCS with the Fence Tick linetype.

DPWALL

Inserts a wall symbol at a point and rotation.

Ribbon · Occupations → Wall

How to use it

Specify insertion point: → Specify rotation <0>:.

What it produces

Wall blocks on SURV OCCS, annotative.
