Topography & Earthworks

Batters, contour labels, surface levels and fill-plan hatching.

Commands

BATTER

Fills the space between a top and toe line with batter ticks, each stretched to span the gap.

Ribbon · Topography → Batter

How to use it

Select top batter curve: → Select toe (bottom) batter curve: → then drag: the distance from the top line divided by the local gap sets the tick spacing, and the whole run previews live. Click to confirm, Esc to cancel.

What it produces

Batter blocks on the BATTER layer, each rotated toward the toe and scaled to span the local gap.

Note — Spacing is adaptive — ticks crowd where the batter narrows. Works on 3D top and toe strings, though the output lands flat.

CONTLAB

Labels a contour with its elevation, sitting the text on the line with a mask through it.

Ribbon · Topography → Contour Label

How to use it

Loops: Select contour <exit>: then drag the label along it. Enter or Esc exits.

What it produces

Masked annotative text on your current layer and style, moved above the contour so the mask reads.

Note — The elevation comes from the contour's start point. Offset and rotation are forced to zero during the drag so the label sits on the line, then your ATC preferences are restored.

LEVTOTXT

Writes surface levels into existing text by picking points.

How to use it

Picks an elevation source first, then loops: Select text: → Select point for level:.

What it produces

Overwrites the picked text with the elevation to one decimal place.

Note — Uses the drawing's TIN surface if there is one, otherwise builds a mesh from 3D faces. Because it samples a surface, your pick only needs to be right in plan — you don't have to snap to 3D geometry. No ribbon button.

Fill plans

FILL1 through FILL11 hatch earthworks depth bands. Each sets its layer then runs a solid hatch behind the boundary, repeating until you press Esc — so you can hatch many lots in one band without re-running.
