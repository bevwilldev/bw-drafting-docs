Sheeting

North points, sheet sets, and building per-lot sales layouts.

Commands

ADDNORTH

Drops a north point already rotated to match a viewport's twist.

Ribbon · Sheeting → North Point

How to use it

Select viewport: — then the symbol follows your cursor; click to place. Esc cancels.

What it produces

A North Point block on layer NORTH, annotative, rotated to the viewport's twist angle.

Note — You can pick the viewport's clip boundary instead of its edge — it resolves to the owning viewport either way.

SSLOAD

Opens this drawing's sheet set, or offers to build one if it doesn't exist.

Ribbon · Sheeting → Sheet Set

How to use it

If a matching .dst sits beside the drawing it opens and saves. Otherwise: No sheet set found for this drawing (name.dst). Create one? [Yes/No] <Yes>: — on Yes it picks a template, adds every paper layout as a sheet, and opens the result.

What it produces

A sheet set named after the drawing, in the drawing's folder.

Note — Requires a saved drawing with at least one paper layout. The template is chosen from the drawing's filename suffix — DP/SP/CP/PP use the plan form template, SET/ID/FW/PEG the setout template, SAL/LOT the lot template, anything else the detail template.

SETLAYOUT

Builds a complete set of per-lot sales layouts — one sheet per lot, each centred and scaled to its own lot.

How to use it

Select the viewport in your MAIN sales layout: → Enter plot scale denominator <200>:. Everything else is automatic.

What it produces

One annotation scale and one layout per lot, each viewport centred on its lot. Tabs are sorted into lot order.

Note — Lot numbers are read as text on the SUB DP layer — so a missing or mis-layered lot number simply won't get a sheet, which makes this a useful QA pass. Pair with INCBLOCK. No ribbon button.

INCBLOCK

Turns each lot into a numbered annotative block that's only visible at its own scale.

How to use it

Enter starting block number: then loop: Select lot to block as "N":. The annotation scale advances after each lot.

What it produces

A block named after each number containing a copy of the lot, referenced on SUB BDY.

Note — The original lot is never consumed — a copy becomes the block content. This is the trick that makes each sales sheet show only its own lot. Create the named per-lot scales first with CSCALE. No ribbon button.
