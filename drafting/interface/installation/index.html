Installation

The suite ships as a single installer covering every plugin, the templates, plot styles and command aliases.

Before you start — close BricsCAD. It writes its settings back when it exits, which would undo the installer's changes. The installer will tell you if it's still running.

Running the installer

  1. Run the installer. It checks you're on the company network before proceeding.
  2. Choose components. Pick a workstation preset from the drop-down, or tick components individually. Every component is optional and each works on its own.
  3. Choose how the environment is delivered (see below).
  4. Finish, then start BricsCAD. The ribbons load automatically.

Delivery modes

Templates, plot styles and command aliases have to land somewhere. The installer offers three options:

ModeWhat happensUse when
Inject into current profileFiles are copied into your existing profile's folders and the office alias is added to your alias file.You know what you're doing and want everything in your existing setup.
Copy profile, then injectYour profile is cloned as <name> (WSY) with local copies of its folders, and the WSY content goes into the clone. Your original is untouched.Recommended. Keeps your settings but never contaminates them.
Fresh WSY profilesNew, separate WSY Drafting / WSY Engineering profiles are created.You want a clean environment that's entirely separate.

Checking it worked

Start BricsCAD. You should see a line on the command line naming the plugins that loaded, and the ribbon tabs should be present. If a tab is missing, see Troubleshooting.

Updating

The suite checks for new releases in the background and tells you on the command line when one is available. Type WSYUPDATE to launch the installer for the new version.
