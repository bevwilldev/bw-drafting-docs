Installation

One installer covers the whole suite. Three quick checks first — the download is just below them.

Before you install

!

Remove older WSY hand-outs first. Uninstall any earlier BricsCAD or AutoCAD tools, plugins, macros, LISP or profile setups Western Sydney Drafting has provided in the past — including any test or beta build of this suite (Windows Settings › Apps). Older hand-outs can clash with this official setup.

  • Expect Windows to warn you. The installer isn't code-signed yet, so your browser may flag the download (in Edge: ⋯ › Keep, then Show more › Keep anyway), and SmartScreen may appear when you run it (More info › Run anyway). First manual install only — automatic updates never show it.
  • Close BricsCAD. It writes its settings back when it exits, which would undo the installer's changes. The installer will tell you if it's still running.

Running the installer

  1. Run the installer.
  2. Answer one question — what is this workstation used for? Tick every discipline that applies: Drafting, Engineering, Surveying — one, two, or all three for the full suite. Departments borrow each other's tools, so any mix is valid; the tools all coexist in one environment while each discipline keeps its own templates.
  3. Optionally, keep your own setup. Tick Keep my toolbars, panels and settings and your existing BricsCAD setup comes across into an office copy of it, using the office templates — nothing of yours is changed or copied. Leave it unticked and the office environment is set up separately, with your own setup untouched either way. (Choosing Advanced instead opens the detailed pages — individual components, delivery and profiles. Keyboard shortcuts are Advanced-only — no preset rebinds your keys.)
  4. Hit Install — that's the whole wizard. Then start BricsCAD: the ribbons load automatically — and from here on, updates install themselves.

Delivery modes (Advanced only)

Templates, plot styles and command aliases have to be placed into a BricsCAD profile. A workstation choice handles this for you — the safest option, or the second one below if you ticked Keep my toolbars, panels and settings — so this page only appears if you chose Advanced, and only when that optional content is selected. The ribbon, commands and tools work in any profile regardless of the choice here. The options, safest first:

Your choice is remembered: when you update later, the installer defaults to the same mode.

Checking it worked

Start BricsCAD. You should see a line on the command line naming the plugins that loaded, and the ribbon tabs should be present. If a tab is missing, see Troubleshooting.

Updating — it's automatic

You never need to come back here for updates. When a new version is released, the suite downloads it quietly in the background and a small status-bar bubble tells you it's ready. Just close BricsCAD — the update installs itself, no wizard, no clicking — and the next time you open BricsCAD you're on the new version, with all your settings and profiles exactly as they were. Want it immediately? Type WSYUPDATE: BricsCAD closes, updates and reopens on its own.

About early access

The suite is in early access: solid enough that the office runs on it daily, but still being rounded out, so the occasional rough edge is part of the deal. It updates itself — fixes usually reach you within a day of being reported, no action needed — and anything odd you hit is worth a quick report (Report a Bug on any ribbon tab gets you there). What you report genuinely steers what gets built and fixed next: you're not just using the tools, you're shaping them.
