This only happens on this first manual install; automatic updates never show it.
Before you start — close BricsCAD. It writes its settings back when it exits, which would undo the installer's changes. The installer will tell you if it's still running.

Running the installer

  1. Run the installer.
  2. Answer one question — which workstation is this? Full suite, Drafting, Engineering or Surveyor. That's it: the right components install and the environment goes into fresh dedicated WSY profiles (your own profile is untouched). Choosing Advanced instead opens the detailed pages — individual components, delivery mode and profiles. (Keyboard shortcuts are Advanced-only — no preset rebinds your keys.)
  3. Finish, then start BricsCAD. The ribbons load automatically — and from here on, updates install themselves.

Delivery modes (Advanced only)

Templates, plot styles and command aliases have to be placed into a BricsCAD profile. A workstation choice applies the safest option (fresh WSY profiles) automatically — this page only appears if you chose Advanced. The options, safest first:

This only matters if you install the optional content. The delivery mode affects your BricsCAD profile only because you ticked templates, plot styles or command aliases. The ribbon, commands and tools work in any profile and are unaffected — if you install just those, this step doesn't even appear.
ModeWhat happensTrade-off
Fresh WSY profilesNew, separate WSY Drafting / WSY Engineering profiles are created for the content. Your own profile is left completely alone.Recommended — safest. Nothing you already have is changed.
Copy my profile, use the copyYour profile is cloned as <name> (WSY) and the WSY content goes into the clone; your original is untouched.Safer than injecting — but the copy uses local folders. If your profile points at network directories (shared templates / support), the copy takes a local snapshot and won't stay live-linked to them.
Inject into current profileFiles are written into your existing profile's own folders (overwriting same-named files, including on a network) and the office alias is added to your alias file.Most invasive — changes your existing setup. Only if you know what you're doing.

Your choice is remembered: when you update later, the installer defaults to the same mode.

Checking it worked

Start BricsCAD. You should see a line on the command line naming the plugins that loaded, and the ribbon tabs should be present. If a tab is missing, see Troubleshooting.

Updating — it's automatic

You never need to come back here for updates. When a new version is released, the suite downloads it quietly in the background and a small status-bar bubble tells you it's ready. Just close BricsCAD — the update installs itself, no wizard, no clicking — and the next time you open BricsCAD you're on the new version, with all your settings and profiles exactly as they were. Want it immediately? Type WSYUPDATE: BricsCAD closes, updates and reopens on its own.
