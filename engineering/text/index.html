Text & Leaders

Annotation at the BW standard heights, with leaders that match.

Text

Four commands, one per standard height. Select text first to reformat it to that height, style and layer, or run with nothing selected to place new text.

CommandHeightLayer
BW252.5 mmT25
BW353.5 mmT35
BW505 mmT50
BW707 mmT70

How to use it

With text selected, run the command and it's reformatted in place. With nothing selected you're asked Text insertion point [ESC to exit] — pick a point, type the text, and it keeps prompting for the next point until you press Esc.

What it produces

Text on the height's layer (T25–T70) in the BW_AN style, created annotative so the plotted size follows the drawing's annotation scale.

Multileaders

BWML25, BWML35, BWML50 and BWML70 place a multileader whose text and arrow are sized to match the same standard height.

How to use it

Run the command and the normal multileader placement takes over — pick the arrow point, the landing, and type the text.

What it produces

A multileader on the matching T-layer using the sized BWAN_ML leader style (2.5 / 3.5 / 5 / 7 mm), annotative, with BW_AN text.

Note — layers and styles are created on demand, so you don't need a particular template for these to work.
