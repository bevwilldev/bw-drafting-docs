Styles & Scales

Setting a drawing up with the BW styles and the standard scale list.

Commands

BWSTYLEIMPORT

Creates the full BW style set without disturbing what's currently active.

Ribbon · Standards → Import Styles

How to use it

No prompts — run it and the styles are added.

What it produces

The BW_AN text style family (BW_AN, BW_AN_Italics, BW_BK_Lotno, BW_AU) and the BWAN_DIM25 / BWAN_DIM35 dimension styles. Your active text and dimension styles are left unchanged.

CSCALE

Creates annotation scales, working out the ratio for you.

Ribbon · Standards → Add New Scale

How to use it

Opens a dialog — enter the drawing units (paper units are fixed at 1) and a name, which auto-fills to the ratio. Use commas for several names at once, or a sequence token like {1-5} from the ▾ menu to create a run of scales in one go.

Note — This is the same tool as on the WSY Drafting ribbon. The older BWCSCALE has been retired — use CSCALE.

BWSCALES

Resets the drawing's annotation scale list to the engineering standard set.

Ribbon · Standards → Reset Scale List

How to use it

No prompts and no confirmation — it runs immediately and reports how many scales were removed and added.

What it produces

The standard engineering scale list — 1:10000 down to 1:10, plus the named layout scales (Layout Plan, Line Marking, Parking Plan, the Turning and Sewer/Water presets, and the MD scales).

Watch out — This wipes the existing scale list before rebuilding it. The active scale and any scales still in use by annotative objects survive, but anything else you'd added is removed. It's deliberately a manual command — it never runs on its own.
